## 📋 Spesifikasi
- **Jangkauan:** Hingga 200 cm (2 meter)
- **Panjang Gelombang Laser:** 940 nm (Aman untuk mata / Eye-safe)
- **Protokol:** I2C (Alamat default: `0x29`)
- **Tegangan:** 3.3V - 5V DC

## 🔌 Skema Wiring (I2C)
| Pin VL53L0X | Pin ESP32 | Pin Arduino Uno |
| :--- | :--- | :--- |
| **VIN** | 3.3V / 5V | 5V |
| **GND** | GND | GND |
| **SCL** | GPIO 22 | A5 |
| **SDA** | GPIO 21 | A4 |
